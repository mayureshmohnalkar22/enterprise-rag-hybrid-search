# Demo screenshot guide

Capture these screens after starting your own environment:

1. `dashboard-upload.png` — dashboard with uploaded documentation and indexed chunk count.
2. `dashboard-answer.png` — one question, its cited answer, latency, and cited chunks.
3. `dashboard-sparse.png` — same exact-term query with BM25 mode.
4. `dashboard-hybrid.png` — same query with hybrid mode.
5. `api-docs.png` — FastAPI Swagger page at `/docs`.
6. `evaluation.png` — terminal showing executed retrieval benchmarks.

For the README, link only real screenshots, e.g. `![RAG query demo](docs/dashboard-answer.png)`.
